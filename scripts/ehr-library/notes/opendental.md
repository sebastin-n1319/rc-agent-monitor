## Open Dental (on-premise server, also Open Dental Cloud)
- Public manual: https://opendental.com/manual/ (the most complete public EHR help; link agents to the exact page).
- Edit Patient Information: Last Name, First Name, Preferred Name, Middle Initial, Title, Salutation. The manual describes no automatic capitalization of names. Status options: Patient, NonPatient, Inactive, Archived, Deceased, Prospective, Deleted; any status other than Patient disables Recall. Gender (Other becomes Unknown on claims); Position = marital status; Home Phone, Wireless Phone, Work Phone; Text OK (blank is treated as No or Yes by the preference "Text Msg OK, assume default is 'No' for patients with no selection"); Email (several separated by commas); Language; Primary and Secondary Provider (changing primary needs the Patient Primary Provider Edit permission). Source: https://opendental.com/manual/patientedit.html
- Appointment confirmation statuses: Setup > Definitions > Appt Confirmed. The first status in the list is the default for new appointments. Each status has Name, Abbrev (shown in the Confirmation Status pick list), Color, and send flags for eConfirmations, eReminders, Arrivals, thank-yous and General Messages. Open Dental's own eService statuses include eConfirmSent, eConfirmCallBack, eConfirmFailure and Created from Web Sched. Source: https://opendental.com/manual/definitionsapptconfirmed.html
- Recall: Setup > Appointments > Recall (types shown in the list, reminder intervals, max reminders, exclusions for patients with a future appointment). Recall types: https://opendental.com/Manual/recalltypes.html. Source: https://opendental.com/Manual/recallsetup.html
- Adit rulebook note: the cloud-hosted database (Open Dental Cloud) needs the client to have access to the server where Open Dental is installed; a database that sits in a third-party cloud with no server access will not integrate.
