## Eaglesoft (Patterson Dental, on-premise server)
- On-premise Windows EHR by Patterson Dental. Third-party tools read patient demographics, family/head of household, appointments (upcoming, past, broken) and insurance (carrier, payer ID, subscriber, group, employer, coverage, deductible, used, remaining) from it. Source: https://help.yapiapp.com/es/en/how-patient-profiles-integrate-with-eaglesoft.html
- Cancelling or no-showing: in the Appointment module right-click the appointment > Delete this Appointment, then choose Failed (no-show) or Cancelled. Keep "Add to QuickFill List" checked; if it is unchecked the whole appointment record is deleted from the database, so no integration can see that it was cancelled or failed. Source: https://help.practicenumbers.com/en/articles/9980100-defining-cancellations-and-no-shows-in-eaglesoft
- Recall: recall types are set up in Lists > General Setup > Recall Types (description, frequency, provider, default type). Multiple recall types need File > Preferences > General > Use Multiple Recalls; otherwise Eaglesoft uses one Next Recall. A service code updates the patient's recall only if Lists > Service Codes > Edit > "Updates Patient Recall" is checked (with the recall type for multiple recalls), for example D1110 prophy. If recall dates are not updating, check this first. Recall must be set up in Eaglesoft before recall reminders from any third party work. Source: https://yapi.zendesk.com/hc/en-us/articles/360000174668
- Patient forms PDFs land in Patient details > SmartDoc (Adit rulebook).
