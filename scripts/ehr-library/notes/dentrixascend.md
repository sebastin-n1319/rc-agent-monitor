## Dentrix Ascend (Henry Schein One, cloud)
- Cloud dental practice management software from Henry Schein One. Public learning site: https://learn.dentrixascend.com/ (courses, videos, release notes).
- Appointment confirmation: Confirmed is set after the patient confirms; Left Message marks a message left, and is changed to Confirmed once they confirm; Ascend keeps a list of unconfirmed appointments. Source: https://learn.dentrixascend.com/?p=32119
- Patient forms PDFs land in Patient > Document Manager (Adit rulebook). Third parties connect through Henry Schein One's API Exchange (approved vendors only). Source: https://www.henryscheinone.com/dental-solutions/api-exchange/api-exchange-customer
