## Dentrix (Henry Schein One, G6 / G7 series, on-premise server)
- On-premise Windows client/server EHR by Henry Schein One. Main modules: Family File (patient demographics, insurance, Medical Alert), Appointment Book, Patient Chart, Ledger, Office Manager (reports, setup), Document Center, Continuing Care.
- Third-party access: Henry Schein One runs the API Exchange; approved vendors only (security assessment, SOC 2 Type II, OAuth 2.0). Practices check the Authorized Vendors list. Source: https://www.henryscheinone.com/dental-solutions/api-exchange/api-exchange-customer
- Appointment statuses are defined in Office Manager > Maintenance > Practice Setup > Definitions, Definition Type = Appointment Status. Each has an ID, abbreviation and definition text; the abbreviation shows in the Status dropdown of the Appointment Information window. Third-party confirmation tools often add their own statuses; integrations read the definition text, so a confirmation status should say "Confirmed" in its text, and an unconfirmed one should not. Source: https://educate.dentalintel.com/en/articles/5528558-how-to-make-appointments-show-as-confirmed-in-dental-intel-with-dentrix
- Breaking an appointment moves it to the Unscheduled List; integrations count a break more than 24 hours before as a cancellation and within 24 hours as a no-show, based on when it was broken. Dentrix allows appointments with only a name and no linked patient record; those cannot be matched to a patient by an integration. Source: https://learn.dentalintel.com/en/articles/1081526-how-to-break-appointments-in-dentrix-to-count-as-cancelled-or-missed
- Adit Help Center has Dentrix articles (e.g. Breaking appointments (Dentrix), Referral tracking (Dentrix)); search the Help Center first.
