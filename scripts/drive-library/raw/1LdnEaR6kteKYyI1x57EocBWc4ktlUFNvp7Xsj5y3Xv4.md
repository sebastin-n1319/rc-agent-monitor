| SECTION 1  \-  What Are Parent / Child Tickets? |
| :---- |

Parent / Child ticketing is a Zoho Desk feature that lets you group multiple related tickets under one umbrella. Use it when a single issue generates multiple inbound contacts, or when a ticket needs to be split into sub-tasks.

| 📂  Parent Ticket The main umbrella ticket. Groups and tracks all related child tickets in one place. Think of it as: "the case that owns all the sub-issues." | 🏷️  Child Ticket A ticket linked under a parent. Can still be worked independently, but is grouped within the bigger issue. Think of it as: "a related ticket that feeds into the bigger picture." |
| :---- | :---- |

**When should I use this?**

| 📢 | Widespread issue \-  Multiple customers report the same problem (e.g., login outage, OTP not arriving). Create one parent ticket for the issue, then associate each inbound ticket as a child. |
| :---- | :---- |

| 🔧 | Sub-tasks needed \-  A single complex ticket needs to be split into smaller tasks handled by different agents. Create child tickets for each sub-task under the parent. |
| :---- | :---- |

| 🔗 | Duplicate reports \-  Two or more tickets turn out to be about the same thing. Associate them as children under one parent \- nothing gets lost. |
| :---- | :---- |

**Key Terms**

| Term | What It Means |
| :---- | :---- |
| **Parent Ticket** | The main umbrella ticket. It owns and tracks all child tickets beneath it. |
| **Child Ticket** | A ticket linked under a parent. Can work independently but is grouped with the parent. |
| **Associate Parent Ticket** | Action done on a child ticket to link it under an existing parent. |
| **Associate Child Tickets** | Action done on a parent ticket to pull existing tickets in as children. |
| **Dissociate Parent** | Removes the parent-child link. The ticket goes back to standalone status. |
| **Child badge** | Label shown in the ticket header once it has been linked to a parent. |
| **Parent badge** | Label shown in the ticket header once it has child tickets attached. |

| ⚠️ | Important Restrictions A child ticket can only have ONE parent. The following CANNOT be used as parents: tickets that are already child tickets, parents with more than 200 children, archived tickets, spam tickets, or tickets in the recycle bin. |
| :---- | :---- |

| SECTION 3  \-  Quick Reference & Agent Tips |
| :---- |

**Which method do I use?**

| Situation | What to Do |
| :---- | :---- |
| **I'm on the ticket and want to attach it under a parent** | Part A \- Associate existing ticket (under "Associate Parent Ticket") |
| **I'm on the parent and want to pull in related tickets** | Part B \- Associate existing tickets (under "Associate Child Tickets") |
| **Multiple customers report the same issue** | Create one parent, then use Part B to group all related tickets as children |
| **I want to create a brand new sub-task ticket** | Part B → click "Create new child ticket" |
| **I want to remove a parent link** | Child ticket → Parent-Child tab → "Dissociate Parent" |

**Agent Tips**

| ✅ | Always check if a parent ticket already exists before creating a new one. Search by account name or issue keyword. |
| :---- | :---- |

| ✅ | When a widespread outage hits (e.g., login issues, OTP failures), designate one ticket as the parent and group all related inbound tickets under it. |
| :---- | :---- |

| ✅ | You can select multiple child tickets in one go in the modal \- just check all the boxes you need before clicking Associate. |
| :---- | :---- |

| ✅ | Closing a parent does NOT automatically close child tickets. Close each child separately as they are resolved. |
| :---- | :---- |

| ✅ | Child tickets still count toward your own queue. Owning a child ticket means you're responsible for resolving it. |
