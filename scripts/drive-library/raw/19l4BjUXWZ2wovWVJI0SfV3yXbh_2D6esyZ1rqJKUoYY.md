# **2\. Lines & Line Management**

### **What are Lines?**

Lines represent the actual phones or extensions used by the practice.

**Line Management** allows us to:

* Associate a user with an extension.  
* Change the label/name displayed on the physical phone.  
* Identify whose phone it is during call transfers.

### **Steps to Configure**

1. Navigate to **Lines / Line Management**.  
2. Locate the required extension.  
3. Click the **Pencil/Edit** icon next to the extension.  
4. Update the **Label Name** and **User Association**.  
5. Save the changes.

### **Important – Phone Reboot**

After changing a label name, the physical phone must be rebooted for the new label to appear.

### **Manual Phone Reboot**

1. Press **Menu** on the phone.  
2. Scroll to the bottom.  
3. Locate the **Reboot** option/icon.  
4. Select **Reboot**.  
5. Allow the phone to restart.

**Training Tip:** If the label has been updated in the system but is not appearing on the physical phone, ask the user to reboot the phone.

# **3\. Blocked Callers**

Blocked Callers allows practices to prevent specific phone numbers from calling them.

### **Navigation**

**Voice Module → Blocked Callers**

### **Steps**

1. Open the **Voice Module**.  
2. Select **Blocked Callers**.  
3. Add the required phone number.  
4. Save the changes.

# **4\. Call Hold**

Call Hold allows staff to temporarily place a patient/caller on hold. While on hold, the caller will hear hold music.

### **Hold / Unhold a Call**

1. Press the **Pause/Hold** button to place the caller on hold.  
2. Press the appropriate button again to resume the call.

### **Change Hold Music**

**Navigation:**  
**Voice Module → Hold Music**

The practice can change the standard hold music to another available recording.

---

# **5\. Call Override**

Call Override temporarily changes the normal routing of incoming calls.

It can be used when the practice is:

* Closed for a holiday.  
* Unexpectedly closed.  
* Temporarily unavailable.

When enabled, calls can be routed to voicemail or an external number.

### **Steps**

1. Go to **Voice Module → Call Override**.  
2. Enable **Call Override**.  
3. Select or verify the required destination.  
4. Save the configuration.

### **Important**

When the practice resumes normal operations, **Call Override must be turned OFF**.

If it remains enabled, incoming calls may continue to bypass the normal call flow.

* Menu prompts

**Voice Module → Audio Library**

3. Record the message.  
4. Save the recording.

### **Option 2 – Upload**

1. Select **Upload**.  
2. Choose the required audio file from the computer.

4. Save/confirm the recording.

Call Recording allows practice calls with patients to be recorded for:

### **Incoming Call Recording**

# **9\. eFax**

eFax allows practices to send and receive faxes digitally without using a physical fax machine.

### **Steps to Send an eFax**

1. Go to the **ADIT Home Screen**.  
2. Click the **Blue \+ icon**.  
3. Select the **Fax Machine icon**.  
4. Enter the required details.  
5. Enter the recipient's fax number.  
6. Attach the required document.  
7. Verify the details.  
8. Send the fax.

### **Important**

The attached document should be in **PDF format**.

Always verify the **fax number and attachment** before sending.

# **11\. Call Flow**

Call Flow determines the path an incoming call takes through the phone system.

It can contain:

* Greeting  
* Menu  
* Schedule  
* Ring  
* Simulring  
* Voicemail

### **Navigation**

**Voice Module → Phone System → Call Flow**

### **Adding an Element**

1. Open **Call Flow**.  
2. Click the **\+ icon**.  
3. Select the required element.  
4. Configure the element.  
5. Arrange the elements in the required order.  
6. Save the changes.

### **Important Call Flow Rules**

| Element | Purpose |
| ----- | ----- |
| **Greeting** | Should always be placed first when a greeting is required. |
| **Voicemail** | Should always be at the end of the relevant call path. |
| **Schedule** | Used for business hours. |
| **Ring** | Used when one specific line or external number needs to ring. |
| **Simulring** | Used when multiple lines/numbers should ring simultaneously. |

### **Example Call Flow**

**Incoming Call → Greeting → Schedule → Business Hours → Simulring → Multiple Staff Phones → No Answer → Voicemail**

## **13.1 Call Hold**

1. Answer the call.  
2. Press the **Hold/Pause** button.  
3. The caller is placed on hold.  
4. Press the appropriate button again to resume the call.

---

## **13.2 Blind Transfer**

A Blind Transfer sends the caller directly to another extension/number without speaking to the receiving person first.

### **Steps**

1. Press **Transfer**.  
2. Enter the destination extension number.  
3. Press **Transfer** again to complete the transfer.

**Example:**  
Patient → Reception → Directly transferred to Billing

---

## **13.3 Attended Transfer**

An Attended Transfer allows the user to speak with the receiving person before transferring the caller.

### **Steps**

1. Press **Transfer**.  
2. Enter the destination extension number.  
3. Speak with the receiving staff member.  
4. Once the recipient is ready, press **Transfer** again.

**Example:**  
Patient → Reception → Reception speaks with Billing → Patient transferred to Billing

### **Transfer Comparison**

| Blind Transfer | Attended Transfer |
| ----- | ----- |
| Transfer → Destination extension → Transfer again | Transfer → Destination extension → Speak with recipient → Transfer again |
| No conversation with recipient first | Speak with recipient first |

---

## **13.4 Playing Voicemail**

1. Locate the **Voicemail** button/option.  
2. Press it.  
3. Follow the phone prompts.  
4. Enter the PIN/credentials if requested.  
5. Select the voicemail message.  
6. Play the message.  
7. Use the available options to manage the message.

**Note:** The exact button may vary depending on the Grandstream or Yealink model.

---

## **13.5 Mute**

Mute stops the other person from hearing the user's microphone while keeping the call connected.

### **Steps**

1. Press the **Mute** button.  
2. Verify that mute is active.  
3. Press **Mute** again to unmute.

**Troubleshooting Tip:** If the caller says, *"I can't hear you,"* check whether the phone is accidentally on Mute.

---

## **13.6 Do Not Disturb (DND)**

DND prevents the phone from ringing for incoming calls according to the phone/system configuration.

### **Enable DND**

1. Locate the **DND** option/button.  
2. Press it.  
3. Verify that DND is displayed as active.

### **Disable DND**

Press the **DND** option/button again.

### **Troubleshooting Tip**

If a user's phone is not ringing, **always check DND first** before making system-level changes.

---

## **13.7 Phone Reboot**

A phone reboot may be required after certain configuration changes, such as updating the phone's label name.

### **Steps**

1. Press **Menu**.  
2. Scroll to the bottom.  
3. Select **Reboot**.  
4. Confirm if prompted.  
5. Wait for the phone to restart.

# **14\. Phone Troubleshooting Quick Guide**

| Issue | What to Check |
| ----- | ----- |
| **Phone is not ringing** | DND enabled; correct user associated with extension; extension active; Call Flow routing; Call Override enabled |
| **Updated label is not showing** | Label saved; correct extension updated; physical phone rebooted |
| **Caller cannot hear the user** | Mute enabled; handset/headset connected correctly; unmute and test again |
| **Need to transfer a call** | Use Blind or Attended Transfer based on the requirement |
| **Calls are routing somewhere unexpected** | Call Flow, Schedule, Call Override, Ring, Simulring, and Voicemail destination |

### **DND Quick Action**

The training also covered the phone shortcut:

* **Long press Mute** → Enable DND  
* **Long press Mute again** → Disable DND
