# **1\. Overview**

## **Purpose of This Playbook**

This playbook provides a comprehensive guide for tech onboarding team members to successfully implement and drive adoption of Adit Pay terminals in dental practices. It covers the complete lifecycle from pre-onboarding through post-implementation support.

## **Terminal Value Proposition**

Key benefits to emphasize with practices:

* **Seamless Integration:** Payments automatically post to patient ledgers in PMS  
* **Improved Efficiency:** Eliminate manual payment entry and reduce front desk workload  
* **Better Patient Experience:** Fast, secure checkout process with professional terminal  
* **Centralized Financial Management:** All payment methods (terminal, text-to-pay, online) in one platform  
* **Real-time Reporting:** Track all transactions instantly through Adit dashboard  
* **No Additional Hardware Costs:** Terminal included with Adit Pay subscription (after equipment purchase)

# **3\. Terminal Registration & Setup**

## **Step-by-Step Terminal Registration**

6. **1\. Power On Terminal**

* Connect power adapter and ensure terminal is fully charged  
* Press and hold power button until Adit logo appears

7. **2\. Connect to WiFi**

* Navigate to Settings → WiFi on the terminal  
* Select practice WiFi network  
* Enter WiFi password carefully (use on-screen keyboard)  
* Verify connection status shows "Connected"

8. **3\. Pair Terminal with Practice Account**

* Terminal will display a unique pairing code (6-8 alphanumeric characters)  
* Log into Adit Pay platform on computer  
* Navigate to Settings → Terminals → Add New Terminal  
* Enter pairing code exactly as shown on terminal  
* Assign a name to the terminal (e.g., "Front Desk Terminal 1")  
* Click "Register" and wait for confirmation

9. **4\. Verify Registration**

* Terminal should display "Registration Successful"  
* Terminal home screen should show practice name  
* Verify terminal appears in Adit Pay dashboard under Terminals section

## **Common Registration Issues & Solutions**

| Issue | Solution |
| :---- | :---- |
| **Terminal won't connect to WiFi** | Verify password is correct (case-sensitive). Check if the network requires additional authentication. Try restarting terminal. |
| **Pairing code not accepted** | Double-check code entry (0 vs O, 1 vs l). Generate new code on terminal. Ensure the terminal and web app are on the same practice account. |
| **Terminal registered but not appearing** | Refresh browser. Check internet connection on both devices. Verify you're viewing the correct location in multi-location practices. |
| **Terminal frozen during setup** | Perform hard reset: Hold power button for 10 seconds. Wait 30 seconds, then power on. Repeat registration process. |

# **4\. Training Workflow**

## **Training Session Structure**

**Recommended Duration:** 45-60 minutes

### **Part 1: Platform Overview (15 minutes)**

* **Payment Posting Configuration** \- Show whether Ledger Option is Enabled or Disabled

* If Enabled: Payments automatically post to PMS ledger  
* If Disabled: Payments must be manually posted  
* Explain the practice's preference and workflow implications

* **Quick Text Feature** \- How to send payment requests via text

* Demonstrate selecting patient and amount  
* Show different payment methods available (card, ACH, etc.)  
* Practice sending a test payment request

* **Refund Process** \- Critical to cover during training

* Navigate to transaction history  
* Locate original transaction  
* Initiate full or partial refund  
* Explain refund processing timeframes (3-5 business days)

* **Bulk Request** \- Only for clients with Practice Analytics

* Show how to select multiple patients  
* Send payment requests in bulk for outstanding balances

### **Part 2: Preferences Configuration (15 minutes)**

Navigate to Preferences → Payment Request Page

10. **1\. Logo Upload**  
11. **2\. Payment Request Text**  
12. **3\. Confirmation Text \- REQUIRED CHANGE**  
13. **4\. Payment Plan & Subscription Templates**  
14. **5\. Direct Payment Method Feature**  
15. **6\. Partial Payment & Text-to-Pay Expiration**

* Check if practice logo is uploaded  
* If missing, assist with upload (recommended: 500x500px, PNG format)

* Navigate to Payment Reminders in Adit Pay Module

# **6\. Troubleshooting Guide**

## **Common Issues & Solutions**

| Issue | Solution |
| :---- | :---- |
| **Terminal won't turn on** | 1\) Check power connection. 2\) Charge for 30+ minutes. 3\) Try different outlet. 4\) Perform hard reset (hold power 10 sec). |
| **Terminal disconnects from WiFi** | Check WiFi signal strength. Move terminal closer to router. Verify network stability. Reconnect to WiFi in settings. |
| **Touch screen unresponsive** | Clean screen with soft cloth. Remove any screen protector. Restart terminal. Check for software updates. |
| **Card reader not working** | Try different card. Clean card reader slot with dry cloth. Ensure card is inserted correctly. Test contactless payment if available. |
| **Payment declined** | Patient should contact their bank. Try different card. Verify correct billing info. Check if card is expired. Offer alternative payment method. |

# **8\. Best Practices for Terminal Adoption**

## **Driving Terminal Usage**

### **Make Terminal the Default Payment Method**

* Position terminal prominently at checkout desk  
* Train staff to default to terminal for all in-office payments  
* Create workflow where terminal is first option presented to patients  
* Only offer alternatives (cash, check) if patient specifically requests

### **Staff Adoption Strategies**

* **Champion Identification:** Identify enthusiastic staff member to be terminal champion  
* **Peer Training:** Have champion train new staff or hesitant team members  
* **Quick Wins:** Celebrate first successful transactions by each staff member  
* **Address Concerns Early:** Listen to staff hesitations and provide targeted support

# **10\. Success Metrics & Adoption Tracking**

## **Key Performance Indicators**

### **Week 1 Targets**

* **Minimum 5 terminal transactions processed**  
* At least 2 different staff members using terminal  
* Zero unresolved technical issues

### **Week 2-4 Targets**

* **50% of in-office payments processed through terminal**  
* All checkout staff trained and using terminal  
* Average transaction time under 60 seconds

### **Month 2+ Targets (Full Adoption)**

* **80%+ of in-office payments through terminal**  
* Payment plans or subscriptions actively being offered  
* Positive staff feedback on terminal efficiency  
* Reduced time spent on payment entry and reconciliation
