# \`Configuration Call Process

## Purpose

The Configuration (Config) Call allows you to walk the client through the Core platform’s settings while simultaneously showing them what you have set up for them and finalizing that configuration to meet their needs.

Remember that we are only concerned with the Core Platform at this phase of onboarding; you will only configure Engage, Pozative, Patient Forms, and eFax at this time.

If your client plans on using Online Scheduling and knows how they want to set it up, you can include it as part of the Core Platform and configure it at this stage. If they are not sure about using OS yet, it is better to save that conversation for the Adoption phase. Keep in mind that configuring OS is very involved and will require the client’s active participation; it may be better to cover it in a separate call than to make the Config Call even longer and risk overwhelming the client with too much information at once. See Adoption Conversations for more information of what OS settings need to be configured.

## Before the Call

#### Offline Configuration

Before the scheduled Config Call, you will set up the Core platform for your client based on the information you have available (from Sales and the Kickoff Call). This is only a preliminary configuration; you will update and confirm the settings once you have the client on the phone.

Some features already have default settings configured. If you already know what changes your client will need, update them now; if not, you can wait until you confirm their preferences on the call.

Each of the Core platform features has some settings that can be configured in advance:

* Engage  
  * Set up Status Mapping in a logical way. Map all statuses to Confirmed or Unconfirmed in a way that makes sense.  
  * Customize any auto-reminders that you know they want/need. Birthday Wishes, Scheduled Confirmations, Appointment Reminders, and Recall Reminders are already set up with default templates, but you should edit them based on the client’s needs, such as:  
    * When to send each message.  
    * To whom each message should be sent.  
    * If they would like to use auto-confirmation on appt reminders.  
  * Customize the text of each auto-reminder message.  
    * Decide if the placeholder for Organization Name or Location Name makes the most sense for this client.  
    * Update the default text if you feel it is appropriate.  
  * Set Preferences for Appointment Date format and Quick Text.  
* Pozative  
  * Make sure their logo has been added.  
  * EHR Integration \- keep on Manual for now, but know which Automatic option you will recommend based on their goals.  
  * Goal \- if you know what their goal is, update it now.  
  * Make sure GMB is connected.  
  * Choose the request flow and settings that will best meet their needs.  
* Patient Forms  
  * Make sure their logo has been added.  
  * Set the Reply-to and Receptionist emails.  
  * Edit the default message text for form requests, resending forms, 2nd signature.  
  * If they have a thank-you page, add it.  
  * Specify which users are able to sign on behalf of the practice.  
  * Customize any of the sample forms you know they need.  
  * Set up any Auto-assign Forms that you know they will want to use.

## Config Call

#### Call Expectations

The Config Call should be scheduled for 60 minutes. During this call, you will confirm the configuration and teach the Office Manager and/or practice admins how to find and update preferences for the Core platform features.

For each Core module, you will:

1. Show the client what you have set up for them already.  
2. Walk them through what each of the settings do.  
3. Explain why you chose the configuration you did for their specific needs and goals.  
4. Encourage the client to discuss these decisions with you and suggest changes.  
5. Make any necessary changes to ensure the final configuration will both work and meet their needs.  
6. Turn on all automated messages and reminders.

#### Call Agenda

The following features and settings should be covered in this call:

* Navigation  
  * Module icons and how to switch between apps  
  * Help menu  
* Voice  
  * How to change recordings for greeting, menu, and voicemail  
  * Where to upload custom hold music  
  * Call recording for outbound calls  
  * Call override setup  
  * How to block callers  
* eFax  
  * Settings \> Numbers \> fax number \> edit  
    * Add who should receive a copy of every incoming fax in the Incoming email field  
* Engage  
  * Auto-Reminders  
    * How to view and edit an auto-reminder  
    * How to toggle an auto-reminder off or on  
    * How to add a reminder  
    * Text vs. Email vs. Voice reminders  
      * Message priority (text/email/both)  
      * Voice priority (cell/home/both)  
    * Spanish reminders  
      * How to set up Spanish reminders  
      * How Spanish reminders are triggered instead of English ones  
    * Customize text of each message (text, email, voice messages customized separately)  
    * How to use placeholders in message text  
    * Define each auto-reminder and what it is used for  
    * Specific settings for each reminder:  
      * Schedule Confirmation:  
        * Add forms to a scheduled confirmation text  
        * Send to new patients/existing patients/both  
      * Appointment Reminders:  
        * Auto-confirmation, confirmation response, mark C as read  
        * Send reminder to (based on appointment status)  
        * When to send before/after appt, hours/days/weeks, time of day  
      * Recall Reminders:  
        * Recall types  
        * Send before/after due date  
        * When to send and time of day  
  * Preferences  
    * Appointment Date format  
    * Default messages for Quick Text \- different from the auto-reminder text  
  * Confirm reminders are configured how the client wants them  
* Pozative  
  * Preferences  
    * Logo  
    * EHR Integration \- recommend Automatic at 7pm, show various automatic options  
    * Goal \- set a goal for how many reviews they want to receive per month  
    * Request Frequency  
    * Connect business pages  
    * Review Request flow  
    * Text or Email or Both  
    * Default review request text, how to use placeholders  
    * Ability to filter (if using Flow A)  
    * Widget \- allows them to embed their reviews on their website (not required)  
  * Insights  
    * Explain that insights give them a summary of their review requests and activity  
* **Patient Forms**  
  * **Preferences** \> Forms  
    * Logo  
    * Reply-to email  
    * Receptionist email  
    * Default message text for form requests, resending forms, 2nd signature  
    * Thank you page  
    * Signers  
  * **Form Builder**  
    * Show the form library  
    * How to edit/customize a form for their needs  
      * Add/remove fields, edit fields  
      * Add/remove sections, edit sections  
      * Add/remove pages, edit pages  
      * Reorder pages, sections, and fields  
    * If they know what they need now, you can help them make those changes on the call, or do them after the call  
    * Encourage the client to attempt these customizations on their own  
  * Auto-assign Forms  
    * Assign forms to new patients/existing patients/both  
    * Advanced Filters based on appt type or treatment code  
    * When to send before/after appt, hours/days/weeks, time of day  
    * Add up to 5 forms to auto-assign to these patients based on the above criteria

Make sure you keep track of your allotted time during this call. If you reach the last 15 minutes or so and still have a lot to cover,  schedule a second call (30-60 minutes) for later the same day or the next day.

#### Turn On Features

By the end of the Config Call, you have turned on all of the configured automations, including auto-reminders, form auto-assignments, automatic review requests, etc. We don’t want to duplicate reminders for that day, so be sure to confirm with your client first:

1. Ask, “Did your current provider send out reminders already today?”  
2. **If yes**, make sure the auto-reminders are configured to go out at the right time, and will go out **tomorrow** instead of today.  
3. **If not**, update their auto-reminders to send out later today (the exact time will depend on what time it is now). After the reminders are sent, go back in and change the timing of each auto-reminder back to the correct time they should go out starting tomorrow.

#### Call Wrap Up

Wrap up the call by making sure the client is comfortable with what you showed them today and happy with the final settings that were agreed upon. Confirm the date and time of their Staff Training. Thank them for their time and congratulate them on using their Adit platform\!

## After the Call

#### Send Follow Up Email

Send a follow-up email to recap the most important parts of the conversation and provide links to any resources that you think the client will find particularly helpful, such as a KB article on building patient forms.

#### Update CRM

There are three fields in the TO-record that refer to configuration:

* Basic Config Complete \- update when you have finished your preliminary offline configuration  
* Config Call Complete \- update when the call is complete and configuration is finished  
* Pref Train Complete \- update when your POC has been trained on settings/preferences

If everything in the Config Call goes as planned, all three of these fields can be updated at the same time at the end of the call.

Once the Config Call is complete and the client is happy with the configuration you’ve set up, click the **Config Complete** transition on the TO-record.
