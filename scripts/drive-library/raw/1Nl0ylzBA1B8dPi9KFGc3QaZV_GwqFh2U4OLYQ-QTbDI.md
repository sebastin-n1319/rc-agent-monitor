**If your customer is using ONLINE SCHEDULING, it is especially important that you check their account and help your customer go through the getting started steps to unlock the OS module.** 

**1\. When the getting started steps are not complete, pages in OS will not be fully accessible.**   
If you want to view the customer’s appointments you can still access it by navigating to “all locations” and going to their appointment page.   
This will tell you if they have been using online scheduling and receiving appointments. 



**2\. You should check all of their existing booking links, especially the ones used on their website.** 

- Open up their website and click on the “book now” buttons. Make sure the booking links look normal.  
- All existing booking links before migrating to the new platform should still work properly and not face any disruptions.   
  - The microsite link from the old OS will automatically be converted to the “**Default booking link**” that you see on the new booking link page  
  - If getting started is not complete, then you can still access this page by going to “All Locations” and seeing the list from there  
    ****  
-  If the booking link isn’t showing any availability, that is a **red flag**. This means you should urgently reach out to the customer and help them reconfigure their OS.   If you see this then make sure to check their operatory/service/provider mapping matrix  
  

**3\. Make sure that if the customer is using Advanced Online Scheduling, then we should be showing real time available slots in the booking link.**   


**4\. Otherwise if they are on basic online scheduling it should show “Morning, Afternoon, Evening” like this.**   


**5\. Also make sure that their available times on their booking link make sense.** 

- For example if there are any odd times like 2AM or 3AM slots available then that is **a red flag**.   
    
- You can look at the Practice’s schedule on the home page to cross reference available time slots
