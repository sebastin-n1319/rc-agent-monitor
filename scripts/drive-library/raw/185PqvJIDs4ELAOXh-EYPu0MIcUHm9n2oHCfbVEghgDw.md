01  |  WHAT IS AUTOMATIONS?
A smarter way to keep your practice on top of every patient follow-up
SET
Set It Once
Configure rules per location — Automations runs in the background every day without manual effort.
WHO
Target the Right Patients
Rules evaluate patient status, type, procedure codes, balances, and more to surface only the right follow-ups.
ACT
Notify Your Team
Create tasks, follow-ups, chat messages, or internal emails so staff always know who to contact and when.

02  |  NAVIGATION
How to Get to Automations
1
Log in to your Adit Web account
2
Click Settings in the top-right corner
3
Select Automations from the menu
4
You'll land on the Automations list view
TIP
Use the All, Active, and Inactive tabs at the top of the list to filter automations by status.

02  |  NAVIGATION
The Automations List View
The list view gives you a birds-eye view of all automations for your location.
All
Every automation available to your location, active or not
Active
Automations that are currently turned on and running
Inactive
Automations that are turned off or not yet configured
Each automation card shows:
Automation name  |  Current Trigger summary  |  Actions summary  |  Edit (pencil) icon

03  |  SELECTING & CONFIGURING
How to Select an Automation to Configure
1
Browse the available automations (e.g., Unconfirmed Appointment, Incomplete Form, Hygiene Recare)
2
Use the All / Active / Inactive tabs to filter the view if needed
3
Locate the automation you want to set up
4
Click the Edit (pencil) icon on the right side of the card to open its configuration
TIP
Each card shows a quick summary of its current Trigger and Actions — review before editing.

04  |  CONFIGURATION — STEP 1
Step 1: Set the Trigger — When It Runs
Define when the automation should evaluate patients.
Time-based before appointment
"24 hours before appointment"
Daily scheduled run
"Every day at 9:00 AM"
KEY
CONCEPT
The trigger determines how often Automations checks for qualifying patients. A well-timed trigger means follow-ups land at the most relevant moment — not too early, not too late.
8

04  |  CONFIGURATION — STEP 2
Step 2: Define Patient Criteria — Who Qualifies
Filter criteria determine which patients the automation will act on. Available filters vary by automation type.
PS

PT
Patient Type
PC

BAL
Balance Thresholds
APT

PRV
Provider
NOTE
Criteria options change based on the Automation Type selected.
9

04  |  CONFIGURATION — STEP 3
Step 3: Choose Reminder Actions — What Happens
Select one or more actions to trigger when a patient matches the criteria. You can combine multiple actions.
TSK
Create a Task
Generates a task for staff to follow up on the patient record
FUP
Create Follow Up
Adds a follow-up entry to the patient record for tracking
MSG
Send Chat Message
Posts an internal chat message to a team member or group
EML
Send Internal Email
Emails the configured staff member(s) internally

05  |  SAVE & ENABLE
Step 4: Save & Activate Your Automation
SAVE
Click the "Save" button to store your configuration. Your trigger, criteria, and action settings are now preserved.
ENABLE
Use the toggle switch on the automation card to activate it. The toggle turns orange when the automation is active.
Toggle States:
Inactive

06  |  ACTIVITY LOG
How to Access the Activity Log
1
Log in to your Adit Web account
2
Navigate to Settings (top-right corner)
3
Select Automations from the menu
4
Click Automations from the left navigation panel
5
From the secondary menu, select "Logs"
6
The Activity Log loads with the All tab selected by default
13

06  |  ACTIVITY LOG
Activity Log — Status Tabs
Filter entries by outcome using the five tabs at the top of the log:
All
Every automation execution within the selected date range
Success
All configured actions completed successfully
Partial Success
Some actions completed but others failed
Filtered
Patients matched but were excluded by additional filter rules
Failed
Actions not completed due to an error
You can also filter using: Search  |  Date Range  |  Automation Type
14

06  |  ACTIVITY LOG
The Detailed Log Table
Each row in the log table contains:
Column
Description
1.  Date & Time

2.  Automation
Type of automation
3.  Details
Detailed log of execution — click the dropdown to expand
4.  Status
Success, Filtered, Failed, or Partial Success
5.  Input / Output
The underlying data sent into and returned from the automation

07  |  ROLE-BASED ACCESS
Who Can Do What?
Access to Automations is controlled by user role:
Full Access
Admin
Owner
Manager
Can configure automations — set triggers, criteria, actions, save and enable.
View Only
Staff
Read-Only
Can view automations and the activity log, but cannot create or edit configurations.
NOTE
If a staff member can't see the Edit icon, check their role — they may be View Only.
